# Module.2
En las siguientes imagenes se pueden apreciar tanto la "Snapshot" que realice de mi VM como el tipo de red
que seleccione para utilizar a futuro,

Decidi utilizar el modo "Red Interna" ya que tengo planeado utilizar mas de una VM, por lo tanto el plan es 
hacer pruebas de ataques en forma controlada entre ambas maquinas y asi poder diagnosticar como se veria un
ataque entre dos maquinas diferentes. El objetivo por lo tanto seria analizar las vulnerabilidades entre ambas
VM, permitiendo asi realizar un diagnostico a profundidad, destacando que puntos de ambas maquinas son los mas
"debiles" para poder realizar las correciones requeridas y, de esta forma, aumentar la seguridad de la VM.
 En caso de falla total, osea llegar a un punto donde la VM es irreparable, se utilizaria la Snapshot para volver
 en el tiempo y reintentar los pasos anteriores
